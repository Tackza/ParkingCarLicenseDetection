# เส้นทางเดินของเครื่อง — ส่งไป `POST /api/lpr/locations`

แอป Mbus Scan เก็บพิกัดของเครื่อง SUNMI ระหว่างจอเปิดและมีกิจกรรมที่กำลังดำเนิน (`components/LocationTracker.js`)
แล้วส่งเป็นชุดทุก 10 วินาที (เดิม 1 นาที — เปลี่ยน 2026-11-27) ไปที่ endpoint ที่มีอยู่แล้วใน **mbus_backend** (`Lpr/DeviceLocationController`, commit `f942d0d`)
ซึ่งเขียนลงตาราง `lpr_device_locations` ที่หน้าธรรมยาตราของแอดมิน (mbus_app_backend) อ่านไปวาดเส้นทางเดิน

> ฉบับก่อนของไฟล์นี้เสนอ `/lpr/device-locations` ให้ทีม backend ทำใหม่ — **ไม่ต้องทำแล้ว** ใช้ `/lpr/locations` ที่มีอยู่

## ข้อมูลที่ส่ง

- ทุก 10 วินาทีขณะเดิน ยืนนิ่ง (ขยับไม่ถึง 5 ม.) นาทีละจุด ตัดจุดคลาดเคลื่อนเกิน 100 ม. และ 0,0 ทิ้ง
- จอดับหรือสลับแอป = ไม่มีจุด ช่องว่างในเส้นคือช่วงจอปิด
- ส่งทุก 10 วินาที ครั้งละไม่เกิน 500 จุด ; หลังออฟไลน์นานจะทยอยส่งทีละชุดทุก 10 วินาที (server จำกัด 120 ครั้ง/นาที/ผู้ใช้)

```json
{
  "comp_id": 8012,
  "project_id": 345,
  "points": [
    { "lat": 14.0712345, "lng": 100.6012345, "accuracy": 6.5, "speed": 1.2, "heading": 90,
      "recorded_at": "2026-11-26 09:05:07" }
  ]
}
```

- **หนึ่งคำขอมี `comp_id` และ `project_id` ได้ค่าเดียว** — แอปจัดกลุ่มเอง (`nextLocationUpload()` ใน `utils/routeTracking.js`)
- `comp_id` ต้องเป็นตัวเลข ≥ 1 — จุดที่เก็บตอนยังไม่ตั้งรหัสเครื่องใช้รหัสปัจจุบันแทน ; ยังไม่ตั้งเลย = ค้างในเครื่อง
- `recorded_at` เวลาท้องถิ่นของเครื่อง (ICT) ; ผู้ใช้มาจาก token ฝั่ง server
- ไม่ส่ง `battery` (แอปไม่มี expo-battery)
- server กันซ้ำด้วย `(comp_id, recorded_at)` และตอบ success แม้ทุกจุดซ้ำ — แอปจึงส่งชุดเดิมซ้ำหลัง timeout ได้

## คำตอบ

- `{ "status": "success", "result": { "received": N, "saved": M } }` → แอปทำเครื่องหมายว่าส่งแล้ว
- อย่างอื่นทั้งหมด → ส่งชุดเดิมซ้ำในรอบถัดไป (10 วินาที) (log `ROUTE_UPLOAD_ERROR` แบบ throttle)
- prod มี endpoint นี้แล้วตั้งแต่ 27 พ.ย. 2026 (mbus_backend main a97a74e)

## PDPA

เป็นข้อมูลตำแหน่งของเจ้าหน้าที่ แอปไม่มีป้ายบอกบนหน้าจอ (มีแค่ไอคอนตำแหน่งของ Android บนแถบสถานะ) และเก็บเฉพาะในกะ
องค์กรควรแจ้งเจ้าหน้าที่เอง กำหนดระยะเวลาเก็บฝั่ง server และจำกัดสิทธิ์คนที่ดูหน้าธรรมยาตรา
